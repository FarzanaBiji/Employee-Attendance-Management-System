===============================================
EMPLOYEE ATTENDANCE MANAGEMENT SYSTEM
Quick Setup Guide
===============================================

📋 REQUIREMENTS:
- XAMPP/WAMP/LAMP (Apache + PHP + MySQL)
- PHP 7.4 or higher
- MySQL 5.7 or higher
- Modern web browser

===============================================
🚀 QUICK SETUP (5 Minutes):
===============================================

1. INSTALL XAMPP
   - Download from: https://www.apachefriends.org/
   - Install and start Apache & MySQL services

2. COPY PROJECT
   - Copy 'Attendance_mgmt' folder to:
     Windows: C:\xampp\htdocs\
     Mac: /Applications/XAMPP/htdocs/
     Linux: /opt/lampp/htdocs/

3. CREATE DATABASE
   a) Open browser: http://localhost/phpmyadmin
   b) Click "New" to create database
   c) Name: attendance_system
   d) Click on the database
   e) Go to "Import" tab
   f) Choose file: database.sql
   g) Click "Go" to import

4. CONFIGURE (Optional)
   - Open config.php
   - Update database settings if needed:
     DB_HOST: localhost
     DB_USER: root
     DB_PASS: (leave empty for XAMPP default)
     DB_NAME: attendance_system

5. ACCESS APPLICATION
   - Open browser
   - Go to: http://localhost/Attendance_mgmt/
   - You'll see the landing page

===============================================
🛠️ TROUBLESHOOTING:
===============================================

Problem: "Connection failed"
Solution: 
- Make sure MySQL is running in XAMPP
- Check database credentials in config.php
- Verify database name is 'attendance_system'

Problem: "Page not found"
Solution:
- Check if Apache is running
- Verify project is in htdocs folder
- Clear browser cache

Problem: "Permission denied for uploads"
Solution:
- Right-click 'uploads' folder
- Properties → Security → Edit
- Give write permissions

Problem: "Login not working"
Solution:
- Make sure database.sql is imported
- Check default credentials
- Clear browser cookies

🔧 CUSTOMIZATION:
===============================================

Change Timezone:
Edit config.php line 8:
date_default_timezone_set('Asia/Kolkata');

Change Shift Timing:
- Login as Admin
- Go to Employee Management
- Edit employee → Update shift times

Change Grace Period:
Edit config.php calculate_late_status():
$grace_period = 15 * 60; // 15 minutes

Change Colors:
Edit assets/css/style.css:
:root section (lines 8-15)
